# Logos

- `schema-studio-mark.svg` — the mark in the dark-theme `accent` (#6b9bff). Use on `bg-0`–`bg-3` in the dark theme.
- `schema-studio-mark-light.svg` — the mark in the light-theme `accent` (#2f5fd0). Use on light surfaces.
- In product UI prefer the `Logo` component, which draws the mark with `var(--accent)` and switches with the theme. Pair the mark with "Schema Studio" set in Geist 600; never recolour, outline or put the mark on an accent fill.
